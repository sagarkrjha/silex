# Silex UI Core (`silex-ui-core`)

Core state machines, WCAG color calculators, and design tokens for the Silex component engine.

## Overview

`silex-ui-core` provides framework-independent primitives and logic:
- Accessible state machines (Dialog, Sheet, Switch, Accordion)
- WCAG 2.1 relative luminance and contrast ratio calculations
- Token design palettes (Obsidian, Pumice, Slate, Ochre)
- WebAssembly (`wasm-bindgen`) and C-ABI export targets
