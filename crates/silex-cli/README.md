# Silex UI CLI (`silex-ui-cli`)

Native command-line tool for scaffolding Silex components, initializing configuration, and managing UI registries.

## Installation via Cargo

```bash
cargo install silex-ui-cli
```

Once installed, the `silex` binary will be available in your PATH:

```bash
# Initialize Silex in your project
silex init

# Scaffold a component into your source directory
silex add button
silex add dialog
silex add switch

# List all available components
silex list
```
